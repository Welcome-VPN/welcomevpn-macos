# Welcome VPN для macOS

Загрузки и обновления клиента Welcome VPN для Mac. Исходный код — в приватном репозитории.

**Скачать:** [последний релиз](https://github.com/Welcome-VPN/welcomevpn-macos/releases/latest) → `WelcomeVPN.dmg`.

Требования: macOS 13 Ventura или новее, Apple Silicon и Intel.

Установка: открыть `.dmg`, перетащить Welcome VPN в «Программы», при первом подключении ввести пароль администратора (один раз — ставится системный helper для туннеля). Приложение обновляется само.

Ключ и подписку выдаёт бот: https://t.me/welcomevpn_bot
